# PG Desk — Tenant App

Built with Expo SDK 54.

## Run

```bash
npm install --legacy-peer-deps
npx expo start
```

## Login

Enter any phone number and OTP `4444`.

## Features

- Phone + OTP authentication
- Tenant signup
- Home dashboard with room info
- My Dues, Notices, Food Menu tabs
- Profile and Edit Profile
- Pending dues screen
- Light / Dark / System theme
- Redux state with persistence
