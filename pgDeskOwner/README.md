# PG Desk — Owner + Manager App

Built with Expo SDK 54.

## Run

```bash
npm install --legacy-peer-deps
npx expo start
```

## Login

Enter any phone number and OTP `4444`.

## Features

- Role selection (Owner / Manager)
- Phone + OTP authentication
- Home dashboard with hostel overview
- Tenants, Rooms, Staff, Finance tabs
- Add Room / Add Staff forms
- Profile and Help screens
- Light / Dark / System theme
- Redux state with persistence
